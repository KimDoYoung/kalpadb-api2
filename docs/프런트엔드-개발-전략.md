# 프런트엔드 개발 전략: DaisyUI + Theme 통합

## 📋 현황 분석

### 현재 상태

- **CSS**: Tailwind CSS를 CDN으로 로드 (스크립트 태그)
- **JS**: Alpine.js도 CDN 방식
- **빌드**: npm 스크립트 설정 완료 (`build:css`, `build:js`)
- **레이아웃**: `templates/layout/default.html` 존재
- **문제점**:
  - 로그인 페이지가 기본 레이아웃을 사용하지 않음 (독립 구성)
  - 페이지별 디자인 통일성 부족
  - Tailwind CDN 환경에서 커스터마이제이션 불가능
  - DaisyUI를 사용할 수 없음 (npm 플러그인 필요)

### 페이지 구조

```
templates/
├── layout/
│   └── default.html          (기본 레이아웃 - 일부만 사용)
├── auth/
│   └── login.html            (layout 미사용 - 독립)
├── diary/
│   ├── create.html, edit.html, list.html, view.html
├── boards/, posts/, jangbi/, apnode/
├── calendar/
├── settings/

    ├── header.html
    ├── sidebar.html
    └── footer.html

├── css/
│   ├── common/common.css     (Tailwind 지시문 포함)
│   ├── kalpadb.css           (번들 CSS)

└── js/
    ├── common/common.js
    ├── kalpadb.js            (번들 JS)
    └── pages/*.js            (페이지별 스크립트)
```

### Phase 1: 기초 환경 구축 (우선순위 높음)

#### 1.1 Tailwind npm 방식으로 전환

**현재**: CDN 로드 (커스터마이제이션 불가)
**목표**: npm 패키지를 통한 로컬 컴파일

```bash
# 이미 설치되어 있으므로 package.json 확인만 필요
```

**작업**:

1. `tailwind.config.js` 강화

   ```js
   module.exports = {
     content: [
       "./src/main/resources/templates/**/*.html",
       "./src/main/resources/static/js/**/*.js"
     ],
     theme: {
       extend: {
         colors: {
           // 브랜드 색상 정의
           primary: '#4285F4',
           secondary: '#34A853',
           // ...
         },
         // 다른 확장들...
       },
     },
     plugins: [],
   }
   ```

2. `common.css`에 변수 정의

   ```css
   @tailwind base;
   @tailwind components;
   @tailwind utilities;

   /* CSS 변수 정의 (theme 전환용) */
   :root {
     --color-primary: #4285F4;
     --color-secondary: #34A953;
     --color-danger: #EA4335;
     /* ... */
   }
   ```

3. `default.html`에서 CDN 제거

   ```html
   <!-- ❌ 제거 -->
   <script src="https://cdn.tailwindcss.com"></script>

   <!-- ✅ npm 빌드 결과물 사용 -->
   <link rel="stylesheet" th:href="@{/css/kalpadb.css}">
   ```

#### 1.2 DaisyUI 플러그인 추가

```bash
npm install -D daisyui@latest
```

**tailwind.config.js 수정**:

```js
module.exports = {
  content: [
    "./src/main/resources/templates/**/*.html",
    "./src/main/resources/static/js/**/*.js"
  ],
  theme: {
    extend: {
      colors: {
        primary: '#4285F4',
        secondary: '#34A853',
      },
    },
  },
  plugins: [require("daisyui")],
  daisyui: {
    themes: [
      "light",
      "dark",
      // DaisyUI 제공 테마 중 추가 선택
      // "cupcake", "bumblebee", "emerald", "corporate",
      // "synthwave", "retro", "cyberpunk", "valentine",
      // ... 총 35개 내장 테마 중 선택
    ],
    darkMode: "class", // data-theme 속성 대신 class 사용 옵션
    logs: false,
  },
}
```

**작업 완료 후**:

```bash
npm run build:css
```

#### 2.4 Alpine.js로 Theme 토글 기능

**파일**: `static/js/common/theme.js`

DaisyUI는 `<html data-theme="light">` 속성으로 테마를 제어합니다:

```js
document.addEventListener('DOMContentLoaded', () => {
  const htmlElement = document.documentElement;
  const themes = ['light', 'dark', 'corporate', 'dracula']; // tailwind.config에 정의된 테마

  // 저장된 theme 로드 (기본값: light)
  const savedTheme = localStorage.getItem('theme') || 'light';
  htmlElement.setAttribute('data-theme', savedTheme);

  // Theme 토글 함수
  window.toggleTheme = function() {
    const currentTheme = htmlElement.getAttribute('data-theme');
    const currentIndex = themes.indexOf(currentTheme);
    const newIndex = (currentIndex + 1) % themes.length;
    const newTheme = themes[newIndex];

    htmlElement.setAttribute('data-theme', newTheme);
    localStorage.setItem('theme', newTheme);
  };

  // Alpine.js 통합
  document.addEventListener('alpine:init', () => {
    Alpine.data('themeManager', () => ({
      currentTheme: savedTheme,
      themes: themes,

      toggle() {
        const index = this.themes.indexOf(this.currentTheme);
        this.currentTheme = this.themes[(index + 1) % this.themes.length];
        htmlElement.setAttribute('data-theme', this.currentTheme);
        localStorage.setItem('theme', this.currentTheme);
      },

      setTheme(theme) {
        if (this.themes.includes(theme)) {
          this.currentTheme = theme;
          htmlElement.setAttribute('data-theme', theme);
          localStorage.setItem('theme', theme);
        }
      }
    }));
  });
});
```

**default.html에 추가**:

```html
<head>
  <!-- ... 다른 태그들 -->
  <link rel="stylesheet" th:href="@{/css/kalpadb.css}">
  <script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
  <script th:src="@{/js/common/theme.js}"></script>
</head>

<body>
  <!-- Header에 Theme 토글 버튼 추가 (DaisyUI 버튼) -->
  <button class="btn btn-ghost btn-circle" onclick="toggleTheme()" title="Toggle theme">
    🌙
  </button>

  <!-- 또는 Alpine.js 활용 -->
  <div x-data="themeManager()" class="dropdown dropdown-end">
    <button class="btn btn-ghost btn-circle">
      <span x-text="currentTheme">light</span>
    </button>
    <ul class="dropdown-content menu bg-base-100 rounded-box shadow">
      <li><a @click="setTheme('light')">Light</a></li>
      <li><a @click="setTheme('dark')">Dark</a></li>
      <li><a @click="setTheme('corporate')">Corporate</a></li>
      <li><a @click="setTheme('dracula')">Dracula</a></li>
    </ul>
  </div>
</body>
```

#### 3.2 DaisyUI 컴포넌트 기반 설계

**목표**: DaisyUI 컴포넌트 + Thymeleaf Fragment 조합

**파일**: `templates/components/` 생성

```
components/
├── button.html       (버튼)
├── card.html        (카드)
├── form-group.html  (입력 그룹)
├── modal.html       (모달)
├── navbar.html      (네비게이션 바)
├── table.html       (테이블)
└── alert.html       (알림)
```

**예시 1** - `components/button.html`:

```html
<!--/* DaisyUI 버튼 컴포넌트 */-->
<th:block th:fragment="primary(text, url, type)">
  <a th:href="${url}" class="btn btn-primary" th:if="${type != 'submit'}">
    [[${text}]]
  </a>
  <button type="submit" class="btn btn-primary" th:if="${type == 'submit'}">
    [[${text}]]
  </button>
</th:block>

<th:block th:fragment="secondary(text, url, type)">
  <a th:href="${url}" class="btn btn-secondary" th:if="${type != 'submit'}">
    [[${text}]]
  </a>
  <button type="submit" class="btn btn-secondary" th:if="${type == 'submit'}">
    [[${text}]]
  </button>
</th:block>

<th:block th:fragment="ghost(text, url)">
  <a th:href="${url}" class="btn btn-ghost">
    [[${text}]]
  </a>
</th:block>
```

**예시 2** - `components/card.html`:

```html
<!--/* DaisyUI 카드 컴포넌트 */-->
<th:block th:fragment="base(title, content)">
  <div class="card bg-base-100 shadow-xl">
    <div class="card-body">
      <h2 class="card-title" th:if="${title}">[[${title}]]</h2>
      <div th:utext="${content}"></div>
    </div>
  </div>
</th:block>

<th:block th:fragment="compact(content)">
  <div class="card bg-base-100 shadow">
    <div class="card-body p-4">
      <div th:utext="${content}"></div>
    </div>
  </div>
</th:block>
```

**예시 3** - `components/form-group.html`:

```html
<!--/* 폼 입력 그룹 */-->
<th:block th:fragment="input(label, name, type, placeholder, required)">
  <div class="form-control w-full">
    <label class="label" th:if="${label}">
      <span class="label-text" th:text="${label}"></span>
      <span class="label-text-alt text-error" th:if="${required}">*</span>
    </label>
    <input th:type="${type ?: 'text'}" th:name="${name}"
           th:placeholder="${placeholder}"
           th:required="${required}"
           class="input input-bordered w-full focus:input-primary" />
  </div>
</th:block>

<th:block th:fragment="textarea(label, name, placeholder, required, rows)">
  <div class="form-control w-full">
    <label class="label">
      <span class="label-text" th:text="${label}"></span>
      <span class="label-text-alt text-error" th:if="${required}">*</span>
    </label>
    <textarea th:name="${name}"
              th:placeholder="${placeholder}"
              th:required="${required}"
              th:rows="${rows ?: 4}"
              class="textarea textarea-bordered focus:textarea-primary w-full"></textarea>
  </div>
</th:block>
```

#### 4.1 npm 스크립트 강화

**package.json**:

```json
{
  "scripts": {
    "build:css": "tailwindcss -i ./src/main/resources/static/css/common/common.css -o ./src/main/resources/static/css/kalpadb.css --minify",
    "build:js": "node ./src/main/resources/static/js/bundle.js && terser ./src/main/resources/static/js/kalpadb.js -o ./src/main/resources/static/js/kalpadb.js",
    "build": "npm run build:css && npm run build:js",
    "watch:css": "tailwindcss -i ./src/main/resources/static/css/common/common.css -o ./src/main/resources/static/css/kalpadb.css --watch",
    "watch:js": "node ./src/main/resources/static/js/bundle.js --watch",
    "dev": "concurrently \"npm run watch:css\" \"npm run watch:js\"",
    "dev:full": "concurrently \"npm run watch:css\" \"./gradlew bootRun\""
  }
}
```
